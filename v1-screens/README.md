## 공통 패턴 (요약)

상세는 [common-patterns.md](./common-patterns.md) 참조.

- **변경 미리보기 모달**: 쿠팡 API 호출 전 필수. 슬롯 A~D 구조. 반영 시간은 쿠팡 API 실측 기준(15분~1시간).
- **자동 로그 배지**: 🤖 자동 / ✍ 수동 / 📸 외부 이벤트 / 🔙 롤백.
- **간단⇄전문가 토글**: 우상단 전역. 같은 URL·데이터, 표면 복잡도만 조절.
- **심각도 색상**: 🔴 긴급(critical) / 🟡 주의(warning) / 🟢 정보(info). 색+아이콘+텍스트 3중 인코딩.
- **방향성 컬러**: 개선=녹 / 악화=적 / 무변동=회. 방향 정의는 데이터 사전 참조.
- **접근성 WCAG 2.1 AA**: 키보드·스크린 리더·대비·터치 타깃 전 준수.
