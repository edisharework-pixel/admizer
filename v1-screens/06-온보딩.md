# 화면 06 — 온보딩 (첫 로그인 플로우)

> 애드마이저 V1 · 화면별 상세 스펙 (6/6)
> 상위 기획: `C:\Users\cjh78\.claude\plans\glowing-sauteeing-cray.md`

## 목적

처음 로그인한 사용자가 **첫 가치(첫 인사이트 카드)**까지 도달하는 경로를 안내한다. 쿠팡 API 연동 없이는 어떤 기능도 의미 없기에, 온보딩은 연동을 중심으로 구성.

## 라우트

| 환경 | 경로 |
|---|---|
| URL | `/onboarding/:step` (`:step` = `welcome` | `connect` | `sync` | `cogs` | `ready`) |
| 진입 조건 | 로그인 사용자 중 `onboardingCompleted=false` |
| 완료 후 | `/dashboard` 리다이렉트 |
| 건너뛰기 | Step 2 이후만 가능 (연동은 필수) |

## 플로우 (5단계)

```
[1 환영] → [2 쿠팡 연동] → [3 최초 동기화] → [4 원가 입력] → [5 준비 완료]
   ▲             ▲ 필수           ▲ 자동           ▲ 선택         ▲
```

## 6.3 Step 3 — 최초 동기화 (자동)

```
┌──────────────────────────────────────────────────────────────────┐
│ ① ─ ② ─ ● ─ ④ 원가 ─ ⑤ 완료                                    │
├──────────────────────────────────────────────────────────────────┤
│ 최근 30일 광고 데이터를 불러오고 있습니다                        │
│                                                                  │
│  ▰▰▰▰▰▰▰▰▱▱▱▱▱▱▱▱▱▱▱▱  42%                                      │
│                                                                  │
│  · 캠페인 목록 (57개)              ✅ 완료                       │
│  · 키워드 데이터 (4,218개)         ⏳ 진행 중                    │
│  · 일별 보고서 (30일)              ⏳ 대기                       │
│  · 영역별 분해 데이터              ⏳ 대기                       │
│                                                                  │
│ 예상 소요: ~{{estimated_minutes}}분. 브라우저 닫아도 백그라운드 │
│                                                                  │
│                              [잠시 기다리기]                     │
└──────────────────────────────────────────────────────────────────┘
```

**진행 중 이동 허용**: 진행 바는 유지하되, 사용자는 Step 4로 이동 가능.

**동기화 시간 추정**

| 규모 | 예상 시간 |
|---|---|
| 캠페인 ≤ 20개, 키워드 ≤ 1,000개 | ~3분 |
| 캠페인 21~100개, 키워드 1,001~5,000개 | ~10분 |
| 캠페인 101~500개, 키워드 5,001~20,000개 | ~30분 |
| 캠페인 500개 초과 (대행사) | 60분+ (안내 모달 + 메일 알림) |

`estimated_minutes`는 쿠팡 API 호출 첫 페이지 응답으로 캠페인·키워드 총 개수를 받은 뒤 선형 추정 계산.

## 데이터 흐름

```
GET  /api/onboarding/state   → { currentStep, completedSteps }
POST /api/onboarding/advance body: { step, payload }
POST /api/coupang/connect    (Step 2)
POST /api/coupang/sync       (Step 3 자동 호출)
GET  /api/coupang/sync/progress  (폴링, Step 3)
POST /api/cogs/bulk          (Step 4 CSV)
POST /api/onboarding/complete
```

Step 3 진행 상태는 WebSocket 또는 3초 폴링으로 진행도 갱신.

## 상태별 UI

| 상태 | 처리 |
|---|---|
| 동기화 실패 (Step 3) | 실패 사유 표시 + [재시도] + [건너뛰기](실패 상태로 대시보드 진입) |
