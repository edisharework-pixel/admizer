## 목적

"언제 무엇을 알릴지, 언제 무엇을 자동 조정할지"를 **한 곳에서 관리**. 또한 캠페인별로 흩어진 키워드 정책(보호·필수·제외)을 전역 마스터로 집약.

> - **이 화면의 규칙(16종+커스텀)** = "액션 자동화 트리거" (내가 명시적으로 정의한 IF-THEN)
> - **화면 04 21개 케이스** = "진단·전략 카탈로그" (룰 엔진이 감지해 조언)
> - 겹치는 지표를 쓰지만, 이 화면은 *내가 만든 자동화*, 화면 04는 *시스템이 발견한 기회*
> - 관련 규칙이 중복되면 이 화면 규칙이 우선(명시적 의도)

## 3.1 서브탭 — 자동 규칙 빌더

### 간단모드 (프리셋 체크박스)

```
┌─ 매출 최적화 자동 조정 ──────────────────────────┐
│ 다음 기본 프리셋을 ON/OFF 하십시오.               │
│ ☑ ROAS 기준 이상 → 예산 ↑ / 목표ROAS ↓           │
│ ☑ 매출 높음+ROAS 낮음 → 예산 ↑ / 목표ROAS ↑     │
│ ☐ 매출·ROAS 모두 낮음 → 예산 ↓ / 목표ROAS ↑     │
│ ☐ 전환율 높음+CPC 낮음 → 예산 ↑ / 목표ROAS ↑    │
│ + 그 외 12가지 규칙 자세히 보기 →               │
│                                                  │
│ 기준값 자동 설정: 최근 30일 데이터의 +2%를 기준점│
│                           [캠페인별 커스텀 →]    │
│                                                  │
│ 실행 방식  ○ 추천만 (알림·대시보드)             │
│            ● 확인 후 실행 (기본)                │
│            ○ 자동 실행 (명시적 OFF)             │
└──────────────────────────────────────────────────┘
```

### 전문가모드 (AND/OR 빌더)

PPT 1206 슬라이드 2 기반. AND 그룹과 OR 그룹을 각각 카드로 추가.

```
┌─ 규칙 1 (AND 그룹) ──────────────────────────────────┐
│                                                     │
│  IF  [광고매출 ▼]  [이전 7일 ▼]  [10% 감소/증가 ▼] │
│  AND [ROAS     ▼]  [이전 7일 ▼]  [5%  감소    ▼]   │
│  AND [전환율   ▼]  [이전 7일 ▼]  [10% 증가/감소 ▼] │
│  AND [광고비   ▼]  [이전 7일 ▼]  [10% 증가/감소 ▼] │
│  [+ AND 조건 추가]                                  │
│                                                     │
│  THEN                                               │
│   ☑ 알림 보내기                                     │
│   ☑ 요약 보고서 생성                                │
│   ○ 자동 실행 ─ 현재 OFF                            │
│                                                     │
│                                    [복제] [삭제]    │
└─────────────────────────────────────────────────────┘

┌─ 규칙 2 (OR 그룹) ──────────────────────────────────┐
│  IF  [ROAS    ▼]  [이전 30일 ▼]  [10% 감소/증가 ▼] │
│  OR  [전환율  ▼]  [이전 3일  ▼]  [5%  감소    ▼]   │
│  OR  [전환비용▼]  [이전 14일 ▼]  [20% 증가    ▼]   │
│  …                                                  │
└─────────────────────────────────────────────────────┘

[+ AND 규칙 추가]  [+ OR 규칙 추가]
```

### 필드·조건·액션 목록

> 용어는 [admizer-v1-data-dictionary.yaml](./admizer-v1-data-dictionary.yaml)의 `ko_short`를 사용.
> 간단모드는 한글, 전문가모드는 한글 + 영문 약어 병기.

| IF 필드 | 비교 방식 |
|---|---|
| 매출, 광고매출, ROAS, 전환율, 전환비용, CPC, 클릭률, 노출수, 광고비, 판매수량 | ±%, 절대값 |
| 기간 | 이전 3/7/14/28/30일, 전주/전월 대비 |

| THEN 액션 |
|---|
| 알림 보내기, 요약 보고서 생성, 목표 ROAS 조정 (±%), 예산 조정 (±%), 캠페인 ON/OFF, 키워드 제외/복원, **이전 설정으로 롤백** (신규) |

**자동 롤백 트리거 (PPT 슬라이드 15 요구사항)**

THEN 액션에 "롤백"을 선택하면 특별 조건 모드:

```
THEN  ● 이전 설정으로 롤백
       복원 기준: [14일 대비 -30% 이상 ▼]
       롤백 대상: ● 최근 자동 변경만   ○ 최근 모든 변경
       최대 롤백 깊이: [3단계 ▼]
       복원 후 알림: ☑ 이메일 ☑ 카카오톡
```

- 매출이 비교 기준 대비 -30% 이상 감소 시 자동으로 가장 최근 변경 로그의 이전 상태로 복원
- 롤백 성공 후 추가 자동 변경은 24시간 쿨다운 (연쇄 롤백 방지)
- 복원도 로그에 새 엔트리로 기록(🤖 + [롤백] 배지)

## 3.3 서브탭 — 키워드 마스터

### 레이아웃

```
┌──────────────────────────────────────────────────────────────────┐
│ 키워드 마스터                                                     │
│ [보호] [필수] [제외]       [캠페인 ▼ 전체]  [검색]  [CSV ↑↓]     │
├──────────────────────────────────────────────────────────────────┤
│ ☐ 키워드         │ 유형   │ 캠페인    │ 추가일     │ 출처       │
│ ☐ 손선풍기       │ 보호   │ 전역      │ 12.01      │ 수동       │
│ ☐ 빨래비누       │ 제외   │ 탄소매트  │ 12.05      │ 제외+수동  │
│ ☐ 한일의료기     │ 필수   │ 전역      │ 11.28      │ 수동       │
│ …                                                                │
├──────────────────────────────────────────────────────────────────┤
│ 선택된 {N}개:  [유형 변경 ▼] [캠페인 이동 ▼] [제거]               │
└──────────────────────────────────────────────────────────────────┘
```

### 3가지 유형

| 유형 | 의미 | 자동화 영향 |
|---|---|---|
| 보호 | 효율 관계없이 매출최적화 유지 | 자동 제외 대상에서 절대 제외 |
| 필수 | 특정 캠페인의 핵심 키워드 | 자동 제외 대상에서 제외 (해당 캠페인만) |
| 제외 | 매출최적화 노출 차단 | 매출최적화에서 제외 + 수동 이관 옵션 |

### 키워드 추가 방식

1. **개별 추가**: 키워드 입력 + 유형 선택 + 캠페인 선택
2. **CSV 업로드**: 템플릿 제공, 3컬럼(키워드, 유형, 캠페인)
3. **기존 캠페인에서 불러오기**: 쿠팡에 이미 등록된 제외 키워드 import
4. **진단 패널의 "필수/제외" 버튼**: 자동 누적 (화면 02)

### 네이버 검색량 조회 (V2 자리)

제외 키워드 각 행 우측에 `🔍 네이버` 아이콘. 클릭 시 V1은 "V2 지원 예정" 툴팁, V2부터 실제 호출.

```
DELETE /api/keywords/:id

```

### 간단/전문가 모드 차이 (키워드 마스터)

| 요소 | 간단모드 | 전문가모드 |
|---|---|---|
| 필터 기본값 | 유형=전체, 캠페인=전체 | 유형 탭 분리(보호/필수/제외 각각) |
| CSV 업로드 | 표시 (템플릿 다운로드 안내 강화) | 표시 (형식 자유도 높음) |
| 네이버 검색량 조회 | 숨김 | 표시 (V2 활성 시) |
| 일괄 이동 | 숨김 | 표시 |
