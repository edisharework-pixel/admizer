대시보드 순이익 KPI 정확도의 핵심.

### 원가 계산 로직

**BE-ROAS (손익분기 ROAS)**
```
BE-ROAS = 판매가 / (판매가 − 원가 − 쿠팡수수료) × 100
```

도출:
- ROAS 정의: 광고매출 / 광고비
- 순이익 = 광고매출 − 광고비 − 원가 − 수수료 (간이 모델)
- 손익분기(순이익=0) 시점의 ROAS를 풀면 위 공식이 도출됨
- 의미: "광고비 × BE-ROAS% = 광고매출"을 만들어야 순이익 0

예: 판매가 89,000 · 원가 45,000 · 수수료 10.5%(9,345)
→ BE-ROAS = 89,000 / (89,000 − 45,000 − 9,345) = 89,000 / 34,655 ≈ **257%**
→ 실제 ROAS가 257% 이상일 때만 광고가 이익. 목표 ROAS는 BE-ROAS × 1.2 = 308% 권장.

**관리 제외 상품 플래그 (PPT 슬라이드 1 NOTES 아이디어)**
- "분석" 체크박스 해제 시 대시보드·인사이트에서 해당 상품 전부 제외
- "0원/0% 상품 숨기기" 상단 토글: 광고비 0원·매출 0원 상품을 자동 제외 (재고처분·단종 상품용)
- 제외된 상품은 회색 처리되어 리스트에선 보이되 집계에서 빠짐

**쿠팡수수료율 매핑**
- V1: 사용자 입력 (CSV 컬럼 `쿠팡수수료%`) 또는 개별 편집
- 카테고리별 기본값 제안(9~15%) 드롭다운 제공 — 화면에 카테고리 표 노출
- V2: 쿠팡 카테고리 API 연동 시 자동 채움

**원가 검증 (방어 UX)**
- 입력된 원가가 판매가의 120% 초과 → 경고 토스트 "원가가 판매가보다 높습니다. 확인하세요."
- 원가 + 수수료가 판매가 90% 초과 → 경고 "마진이 매우 낮습니다. BE-ROAS 1,000% 이상"
- 원가 미입력 상품은 대시보드 **광고 순이익** KPI에서 제외 + 경고 표시

**순이익 라벨 주의**
- 대시보드 KPI는 **"광고 순이익"** (부가세·쿠폰·프로모션·배송비·반품 미반영)
- 실제 정산액과 차이가 남을 UI에 반드시 툴팁으로 명시
- 계산식: `광고매출 − 광고비 − (광고매출 × (원가율 + 수수료율))`
