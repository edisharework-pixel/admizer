## 목적

캠페인 단위 진단·실행의 **작업 공간**. 대시보드에서 발견한 문제를 여기서 해결한다. 4개 서브탭으로 구분해 각 탭이 한 가지 일(진단 / 기간 비교 / 로그·롤백 / 노출시간 관리)에 집중한다.

## 라우트

| 환경 | 경로 |
|---|---|
| URL | `/campaigns/:tab` (`:tab` = `diagnose` | `compare` | `logs` | `schedule`) |
| 기본 진입 | `/campaigns/diagnose` |
| 딥링크 | `?campaignId=1234` auto-select, `?filter=low_roas` 사전 필터 |

## 전체 레이아웃

```
┌──────────────────────────────────────────────────────────────────┐
│ 광고캠페인 분석·관리                      [간단⇄전문가] [새로고침] │
├────────────┬─────────────────────────────────────────────────────┤
│ 진단       │                                                      │
│ 기간 비교  │              [선택한 서브탭 콘텐츠]                   │
│ 변경 로그  │                                                      │
│ 노출시간   │                                                      │
└────────────┴─────────────────────────────────────────────────────┘
```

좌측 세로 탭. 탭 라벨 옆 배지 카운트 규칙:

| 탭 | 배지 | 의미 |
|---|---|---|
| 진단 | "진단 (N)" | 룰 엔진이 **critical + warning** severity로 매칭한 캠페인 개수 (info 제외) |
| 기간 비교 | 없음 | 상태성 없음 |
| 로그 | "로그 (N)" | 최근 7일간 `🤖` 자동 + `✍` 수동 변경 건수 합산 |
| 노출시간 | "시간 (N)" | 비노출 구간 활성된 캠페인 수 (설정이 걸린 캠페인) |

배지는 0일 때 숨김. 30초마다 재조회.

### 데이터 흐름

```
GET  /api/campaigns?mode=simple|pro&filter=…&sort=…
GET  /api/campaigns/:id/diagnose?period=14d
POST /api/campaigns/:id/actions/preview  body: { actionType, keywords, … }
POST /api/campaigns/:id/actions/commit   body: { previewToken }
```

preview → commit 2단계. previewToken 유효 60초. commit 요청에는 **Idempotency-Key 헤더** 필수(클라이언트 UUID). 동일 키 재호출 시 서버는 첫 결과 반환(중복 커밋 방지). commit 성공 시 자동 로그 기록(`logs` 탭에 즉시 반영).

**쿠팡 API 레이트 리밋 대응**
- 대량 키워드 일괄 변경 시 분당 호출 제한(공식 확인 중) 초과 가능
- 큐잉 + 지수 백오프(1s → 2s → 4s → 8s → 16s, 최대 5회)
- 진행률 모달: "318개 중 142개 처리 중… 예상 남은 시간 45초" + [중단] 버튼
- 중단 시 처리된 항목만 커밋, 잔여는 롤백 없이 보류 (다시 preview → commit 가능)

## 2.2 서브탭 — 기간 비교 분석

### 레이아웃

```
┌──────────────────────────────────────────────────────────────────┐

├──────────────────────────────────────────────────────────────────┤
│ 지표        │  기준       │  비교       │  증감               │
│ 노출수      │  375,000    │  250,000    │  ↑ 50.0%            │
│ 전환율      │  7.5%       │  5.2%       │  ↑ 2.3%p            │
│ ROAS        │  350%       │  280%       │  ↑ 70%p             │
│ CPC         │  423        │  800        │  ↓ 47.1%            │
│ …                                                                │
├──────────────────────────────────────────────────────────────────┤
│ [그래프: 꺾은선 ⇄ 막대 토글]  호버 시 날짜·값 툴팁             │
│  — 기준 기간(실선) — 비교 기간(점선)                             │
└──────────────────────────────────────────────────────────────────┘
```

### 핵심 규칙

- **좌·우 기간 완전 독립** — 기준 기간 변경이 비교 기간에 자동 반영되지 않음 (PDF에 명시된 특허 포인트)
- 지표 증감 색상: 녹(개선) / 적(악화) / 회(무변동). 방향성은 지표별 정의:
  - 상승=개선: 매출, 광고매출, ROAS, 전환율, 클릭률, 판매수량
  - 하락=개선: CPC, ACOS, 광고비(동일 매출 대비)
- 캠페인 필터: 전체 / 매출최적화만 / 수동만 / 개별 선택
- 그래프 X축: 기준과 비교를 **동일 길이로 정규화**(예: 기준 20일, 비교 20일 → 1~20일째 매칭)

### 데이터 흐름

```
GET /api/compare?baseStart=…&baseEnd=…&compareStart=…&compareEnd=…
    &campaigns=…&fields=…
    → { metrics: [...], timeseries: [...] }
```

### 수락 기준

- [ ] 기준·비교 기간을 서로 다른 길이로도 설정 가능 (예: 7일 vs 30일)
- [ ] 증감 표시는 절대값/%를 토글 가능
- [ ] CSV 내보내기 버튼으로 표 전체 다운로드
- [ ] URL 쿼리에 기간 저장 → 북마크로 같은 비교 재현 가능

### 2.2 간단/전문가 모드 차이

| 요소 | 간단모드 | 전문가모드 |
|---|---|---|
| 표시 지표 | ROAS · 전환율 · CPC · 매출 · 광고비 | 전체 9개 |
| 그래프 | 꺾은선만 | 꺾은선/막대 토글 |
| 빠른 선택 | 전주 동기만 | 전년·전월·전주 + 커스텀 |
| CSV 내보내기 | 숨김 | 표시 |

> 좌·우 기간 완전 독립은 특허 포인트가 아닌 **핵심 차별 UX**로 표기. 특허 가능성은 변리사 검토 결과에 따라 판단 (상위 기획 참조).

```

### 수락 기준

```

### 핵심 규칙

- 매출 최적화: ROAS 변경 **AND** 예산 변경 (둘 다 적용되어야 사실상 중단)
- 수동 성과형: CPC 변경 **OR** 광고 OFF (택일)
- 상품 여러 개 선택 시 일괄 적용
- 저장 시 **변경 미리보기 모달** 경유

### 시간대별 예산 프로파일 (신규)

기술 검토 TXT 8번 요구사항. 비노출 구간만이 아니라 **구간별 다른 예산**을 설정:

```
┌──────────────────────────────────────────────────────────────┐
│ 시간대별 예산 프로파일                                         │
│                                                              │
│ ○ 단일 예산 (기본)                                            │
│ ● 구간별 예산                                                 │
│                                                              │
│ 프리셋: [🌙 새벽형] [🌞 피크형] [🌃 야간형] [⚙ 커스텀]        │
│                                                              │
│ 커스텀:                                                      │
│  00:00~07:00   [ 2,000원 ▼]   (새벽 최소)                    │
│  07:00~09:00   [ 5,000원 ▼]   (출근 피크)                    │
│  09:00~18:00   [ 3,000원 ▼]   (낮 평상시)                    │
│  18:00~22:00   [10,000원 ▼]   (저녁 피크)                    │
│  22:00~24:00   [    OFF ▼]   (심야 중단)                    │
│                                                              │
│ ⚠ 쿠팡 공식 day-parting API 지원 미확인. PoC 결과에 따라     │
│   크론 기반 수동 변경으로 구현하거나 V2 이관.                  │
│                                                              │
│                                       [설정 저장]            │
└──────────────────────────────────────────────────────────────┘
```

### 간단/전문가 모드 차이 (노출시간)

| 요소 | 간단모드 | 전문가모드 |
|---|---|---|
| 예산 프로파일 | 단일 예산 + 프리셋 3종 (🌙🌞🌃)만 | 커스텀 편집 + 요일별(월~일 다른 설정) |
| 히트맵 | 평일/주말 2행 축약 | 요일 7행 |
| 조건 방식 | 프리셋 기반 | AND/OR 명시적 조건 편집 |
