# 애드마이저 V1 — 공통 UI 패턴

> 모든 화면(01~06)이 참조하는 공유 컴포넌트·규칙 모음.
> 개별 화면 스펙에서 "공통 패턴 참조"라고 표기된 항목의 정본.

## 1. 변경 미리보기 모달 (Change Preview Modal)

쿠팡 API 호출 전 **반드시 경유하는** 확인 다이얼로그. 모든 실행성 액션의 마지막 관문.

### 구조 (Slotted Template)

```
┌──── {{모달 타이틀}} ────────────────┐  ← 슬롯 A: 제목
│ 이 작업은 쿠팡 API에 반영됩니다.    │  ← 고정 상단 고지
│                                    │
│ [영향 요약 영역]                   │  ← 슬롯 B: 변경 전/후 비교 또는 복원 리스트
│                                    │
│ [예상 결과 영역 — 선택]             │  ← 슬롯 C: 예상 영향(선택)
│                                    │
│ ⚠ {{반영 시간 고지}}                │  ← 슬롯 D: 반영 지연 안내 (현실 시간)
│                                    │
│ [취소]            [확인 · 적용]    │  ← 고정 하단 버튼
└────────────────────────────────────┘
```

### 슬롯별 필드

| 슬롯 | 내용 | 예시 |
|---|---|---|
| A. 타이틀 | "{액션 이름} ({캠페인명})" | "제외 키워드 추가 (탄소매트)" |
| B. 영향 요약 | 변경 전·후 표 또는 복원 항목 리스트 | "제외 키워드 23 → 38 (+15)" |
| C. 예상 결과 | ROAS·광고비 예측 범위 (선택) | "예상 ROAS 영향: +18~+32%" |
| D. 반영 시간 | 쿠팡 API 엔드포인트별 현실 시간 | "일반적으로 15분 내 반영, 최대 1시간" |

### 반영 시간 고지 실제 표현 (PoC 결과 반영)

공식 문서와 실측 기반:

| 변경 유형 | 쿠팡 반영 예상 | UI 표기 |
|---|---|---|
| 예산 변경 | 5~15분 | "일반 15분 내 반영" |
| 목표 ROAS 변경 (매출최적화) | 15~60분 | "15분 ~ 1시간 내 반영" |
| 키워드 CPC 변경 (수동) | 1~5분 | "수 분 내 반영" |
| 키워드 제외 | 10~30분 | "30분 내 반영" |
| 캠페인 ON/OFF | 1~5분 | "수 분 내 반영" |

**절대 "15초" 같은 비현실적 숫자 금지.** 기존 스펙의 "15초" 표기는 PoC 후 위 기준으로 업데이트.

### 상세 화면별 컨텐츠 매핑

| 화면 | 액션 | A 타이틀 | B 영향 요약 | C 예상 결과 | D 반영 시간 |
|---|---|---|---|---|---|
| 02.1 진단 실행 | [제외+수동] 실행 | "키워드 이관 ({캠페인})" | "제외 23→38, 수동 120→135" | "ROAS +18~32%" | "30분 내" |
| 02.3 롤백 | [이전 설정으로 롤백] | "롤백 확인 ({날짜})" | "복원될 항목 리스트" | 없음 | "수 분 내" |
| 02.4 노출시간 저장 | [설정 저장] | "노출시간 설정 ({캠페인 N개})" | "시간대 구간 + 설정값" | "예산 효율 테스트 필요" | "15분 내" |
| 03.1 규칙 자동 실행 ON | 토글 + 비밀번호 | "자동 실행 활성화 ({규칙명})" | "트리거 조건 + 영향 캠페인 수" | 없음 | 즉시 (규칙 매칭 시) |
| 04.1 인사이트 [적용] | 액션 플랜 단계 | 해당 단계 제목 | 룰 YAML action_template 구체화 | LLM 예측 | "30분 내" |

### 에러·재시도

- 미리보기 호출 실패 → "잠시 후 다시 시도하세요" + [다시 계산]
- previewToken 만료(60초) → 자동 재계산 + 토스트 "값이 변경되어 다시 계산했습니다"
- commit 호출 실패 → 구체 에러 + [다시 시도] (Idempotency-Key 그대로 재사용)
- 레이트 리밋(429) → 지수 백오프 자동 재시도 + 진행 모달

## 2. 자동 로그 배지

변경 로그 및 인사이트 카드 어디에서나 사용.

| 배지 | 유형 | 기록 방식 |
|---|---|---|
| 🤖 | 시스템 자동 | API commit 시 자동 기록 |
| ✍ | 사용자 수동 | 진단 패널 [실행] 또는 [이벤트 기록] |
| 📸 | 외부 이벤트 | 썸네일·상세페이지 변경 등. 사용자가 수동 입력 |
| 🔙 | 롤백 | 자동·수동 롤백 구분용 접미 배지 |

## 3. 심각도·방향성 색상

### 심각도 (룰 YAML severity와 1:1)

| 배지 | 키 | 색상 | 텍스트 라벨 | 용도 |
|---|---|---|---|---|
| 🔴 | critical | #D9534F | 긴급 | 즉시 대응, 매출·수익 손실 확정 |
| 🟡 | warning | #F0AD4E | 주의 | 48시간 내 대응 권장 |
| 🟢 | info | #5CB85C | 정보 | 참고, 기회 탐색 |

**접근성**: 색만으로 구분하지 않는다. 아이콘(🔴🟡🟢) + 텍스트 라벨("긴급"·"주의"·"정보") 병기 필수.

### 방향성 (지표 증감 색상)

데이터 사전 `direction` 섹션 참조.

- **up_is_good** (↑ 녹, ↓ 적): revenue, ad_sales, net_profit, roas, cvr, ctr, orders, impressions, clicks, aov
- **down_is_good** (↓ 녹, ↑ 적): cpc, cpa, acos, ad_spend
- **복합**: budget_utilization — 70~95% 회(정상), >95% 적(경고), <60% 황(경고)

## 4. 모드 토글 (간단 ⇄ 전문가)

### 전환 방식

- 전역 우상단 토글 스위치
- URL 쿼리 `?mode=simple|pro` + 로컬스토리지 저장
- 사용자별 기본값은 화면 05.4 표시 설정에서 설정
- 전환 시 페이지 이동 없이 현재 화면만 재렌더

### 각 화면 간단/전문가 차이 (요약)

전체 차이 표는 각 화면 스펙 내 "간단/전문가 모드 차이" 섹션 참조.

### 데이터 동일성 원칙

- 데이터는 항상 동일, **표면 밀도만 조절**
- 간단모드에서 내린 결정은 전문가모드에서도 동일 효과 (프리셋 체크박스 = 내부적으로 AND 그룹 규칙)

## 5. 접근성 (WCAG 2.1 AA 준수)

모든 화면 공통 적용:

### 키보드

- 전 기능 키보드 접근 가능 (Tab·Shift+Tab, Enter, Space)
- 포커스 표시 1.5px 이상 outline 보장
- 모달 열릴 때 포커스 트랩, ESC 닫기
- 토글·버튼은 `role="button"` + `aria-pressed`

### 스크린 리더

- KPI 숫자는 `aria-label="{지표명} {값} {단위}, 전주 대비 {증감}"` 완전 문장 제공
- 그래프는 `<table>` 데이터 대안 제공
- 아이콘 단독 버튼은 `aria-label` 필수 (🔔 = "알림")
- 실시간 업데이트는 `aria-live="polite"` 영역

### 색상·대비

- 본문 텍스트 대비율 ≥ 4.5:1
- 큰 텍스트(18pt+) 대비율 ≥ 3:1
- 색맹 대응: 녹/적 구분은 화살표(↑↓)·아이콘 병기. 심각도는 색·아이콘·텍스트 3중 인코딩
- 다크모드 V2

### 터치

- 모바일·태블릿 터치 대상 최소 44×44pt
- 온보딩(모바일 지원)과 모바일 읽기 전용 뷰에만 해당

### 텍스트

- 확대 200% 시 가로 스크롤 없이 읽힘
- 줄 간격 1.5 이상
- 영문 약어는 `<abbr title="…">` 툴팁

## 6. 에러 상태

| 상태 | 처리 |
|---|---|
| 로딩 | 스켈레톤 스크린 (구체 높이·개수 유지) |
| 빈 데이터 | 일러스트 + 다음 행동 CTA |
| 쿠팡 API 오류 | 상단 노란 배너 + 마지막 캐시 데이터 노출 + [재시도] |
| 레이트 리밋 (429) | 자동 지수 백오프 + 진행 모달 |
| 네트워크 타임아웃 | "연결 확인 중…" 3회 재시도 후 오류 UI |
| 인증 만료 | 세션 만료 모달 + 로그인 유지 |
| 권한 없음 | "이 기능은 {플랜명}에서 사용 가능" + 업그레이드 CTA |
| LLM 생성 실패 | 룰 YAML `action_template` fallback + 재생성 버튼 |
| 프리뷰 토큰 만료 | 자동 재계산 + 토스트 |

## 8. 데이터 동기화

- 쿠팡 보고서 자동 동기화: 매 1시간 (Pro 플랜은 15분 ~)
- 동기화 상태는 우상단 ⚙ 아이콘 배지로 표시 (최근 성공/실패)
- 실패 시 노란 배너 "동기화 문제 발생, 마지막 성공 N시간 전" + [재시도]

---

## 9. 국제화·시간대

- V1: 한국어만
- 시간대: `Asia/Seoul` 고정 (사용자 설정 가능하나 기본값 고정)
- 날짜 표기: `YYYY.MM.DD` 또는 `YYYY-MM-DD`
- 금액: 원(₩) 기본, 표시 설정에서 "만원" 변환 선택 가능
